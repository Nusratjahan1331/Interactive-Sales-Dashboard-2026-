# Executive Sales Performance Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive **Executive Sales Performance Dashboard** developed using Microsoft Power BI. The dashboard provides a comprehensive overview of sales performance, revenue trends, profitability, and geographical sales distribution.

The main objective is to transform sales data into meaningful business insights through interactive visualizations and dynamic KPI measurements.

## 🎯 Key Features

- **KPI Cards:** Total Revenue, Total Quantity, Total Orders, Total Gross Profit, and Gross Margin.
- **Monthly Analysis:** Revenue and Gross Profit trends by month.
- **Country Analysis:** Top 5 and Bottom 5 countries based on revenue.
- **Sales Channel Analysis:** Revenue comparison across different sales channels.
- **Product Analysis:** Gross Profit contribution by product category.
- **Geographical Analysis:** Country-wise sales performance using map visualization.
- **Interactive Filters:** Month, Quarter, Product Category, and Country slicers.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Calendar Table
- Data Modeling
- Data Visualization
- Interactive Slicers & KPI Cards

## 📈 Key Analytical Components

- Developed DAX measures for business performance indicators.
- Created a Calendar Table for time-based analysis.
- Analyzed monthly revenue and gross profit trends.
- Compared country-level sales performance.
- Evaluated revenue distribution across sales channels.
- Analyzed product category-wise gross profit contribution.

## 💡 Project Objective

The objective of this project is to demonstrate practical Power BI skills, including data modeling, DAX calculations, time-based analysis, and interactive dashboard development.
